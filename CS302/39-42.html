Lecture 39: State Machines (Moore vs. Mealy)

Every sequential circuit that follows a specific pattern of states is called a Finite State Machine (FSM). There are two primary types of FSMs used in digital design: Moore and Mealy.

1. The Moore Machine

Definition: In a Moore machine, the outputs depend ONLY on the current state of the flip-flops (memory). The external inputs only determine what the next state will be, but they do not affect the current output directly.

Characteristics:

  • Safer and highly stable (outputs only change on a clock edge when the state changes).
  • Usually requires more states to complete a task.
  • In a state diagram, the output is written inside the state circle.

2. The Mealy Machine

Definition: In a Mealy machine, the outputs depend on the current state AND the current external inputs.

Characteristics:

  • Faster, because the output reacts to input changes immediately without waiting for the next clock edge.
  • Requires fewer states than a Moore machine.
  • In a state diagram, the output is written on the transition arrow (Input/Output).
Roman Urdu:
Farz karein aap ek ATM machine (State Machine) bana rahay hain.
Moore: Jab machine "Cash Dispense" wali state mein aati hai, tabhi paise bahar aate hain. Button (input) dabane se sirf state change hoti hai.
Mealy: Output state aur button dono par depend karta hai. Jaise hi aap button dabate hain, state change hone ka wait kiye bina output foran mil jata hai. Yeh fast hota hai, lekin isme "glitches" (jhatkay) aane ka khatra hota hai agar input fluctuate kare.

3. Implementing FSMs in ABEL

In ABEL, we can implement both. We use WITH statements inside the STATE_DIAGRAM block to define the outputs for specific states (Moore) or specific transitions (Mealy).

Quick Revision: Lecture 39

  • FSM: Finite State Machine (A sequential circuit with fixed states).
  • Moore Machine: Output = f (Current State). Output is immune to immediate input glitches.
  • Mealy Machine: Output = f (Current State + Current Input). Faster, requires fewer states.

Lecture 40: State Machine Applications

To fully understand state machines, engineers design real-world controllers. Typical examples include Traffic Light Controllers, Elevator Controllers, and Vending Machines.

1. Design Example: Traffic Light Controller

A simple intersection has a Main Street and a Side Street. The controller must cycle through Green, Yellow, and Red lights based on a Timer and Vehicle Sensors.

The States:

  • State 0: Main = GREEN, Side = RED.
  • State 1: Main = YELLOW, Side = RED.
  • State 2: Main = RED, Side = GREEN.
  • State 3: Main = RED, Side = YELLOW.

The Inputs & Logic:

The state machine stays in State 0 as long as a car is detected on Main Street and the long-timer hasn't expired. Once the timer expires (or no cars are detected), the state transitions to State 1. Since this is a Moore Machine, the lights (outputs) are strictly tied to the current state.

Roman Urdu: Jab hum real-world problem solve karte hain toh usko hisson mein baant lete hain. Traffic light mein hum 4 states banate hain. Har state mein lights ki condition fix hoti hai (yeh Moore machine hai). Inputs (jaise timer ya car sensor) sirf yeh faisla karte hain ke abhi is state mein rukna hai ya agli state mein jana hai. ABEL programming ke zariye is poore system ko ek single PLD (jaise GAL) chip par program kiya ja sakta hai.

2. Importance of the "Reset" State

When any digital state machine powers on, its flip-flops might power up in a random state (e.g., 11 instead of 00). Therefore, every state diagram MUST have a Master Reset condition that forces the system into an initial safe state (like making all traffic lights Red) when a Reset button is pressed.

Quick Revision: Lecture 40

  • Application: FSMs are used to control sequences (Traffic lights, elevators).
  • State Assignment: Assigning binary numbers (00, 01, 10) to physical states (Green, Yellow, Red).
  • Master Reset: Crucial to prevent the system from starting in a random or dangerous state upon power-up.

Lecture 41: Memory Architecture and Timing (SRAM)

We transition from logic design to the physical operation of Memory ICs. We focus on SRAM (Static RAM) which uses latches to store data and is incredibly fast.

1. Memory Control Signals

Every memory chip has three primary control lines:

  • CS' (Chip Select) or CE' (Chip Enable): Turns the IC on or off. Active-Low.
  • WE' (Write Enable): When 0, the CPU writes data into the memory.
  • OE' (Output Enable): When 0, the memory sends data out to the CPU (Read).

2. The Read Cycle (Timing Diagram)

Data cannot be read instantly. The CPU must follow a strict timing protocol.

Read Cycle Steps:
1. CPU places the Address on the Address Bus.
2. CPU activates CS' (sets to 0).
3. CPU activates OE' (sets to 0). WE' remains 1.
4. The memory needs time to process this. After a delay, data appears on the Data Bus.
Access Time (tACC): The time delay between when the Address becomes valid and when the valid Data finally appears on the output pins.

3. The Write Cycle (Timing Diagram)

Write Cycle Steps:
1. CPU places the Address on the Address Bus.
2. CPU places the Data to be stored on the Data Bus.
3. CPU activates CS' and pulses the WE' (Write Enable) pin LOW.
4. The data is written on the trailing edge (0 to 1 transition) of the WE' pulse.
Roman Urdu: Memory se data parhna (Read) ya usme data likhna (Write) bilkul ek post office jaisa hai. CPU pehle address batata hai ke kahan se data lana hai. Phir thori der baad memory data bahar nikalti hai. Ye jo thori der lagti hai usko "Access Time" kehte hain. Tabi CPU aur RAM ko sync mein rakhne ke liye Timing Diagrams parhi jati hain taake CPU jaldbazi mein ghalat data na parh le.

Quick Revision: Lecture 41

  • Control Pins: CS' (Chip Select), WE' (Write Enable), OE' (Output Enable).
  • Read Cycle: Provide Address → Enable CS' & OE' → Wait for Access Time (tACC) → Read Data.
  • Write Cycle: Provide Address & Data → Pulse WE' low. Data is saved when WE' goes back high.

Lecture 42: Dynamic RAM (DRAM) & Address Multiplexing

1. Static RAM vs. Dynamic RAM

SRAM uses flip-flops (transistors) to hold 1s and 0s. It is fast but physically large.
DRAM uses a tiny capacitor and a single transistor to hold a bit. Because capacitors leak charge over time, DRAM forgets its data unless it is constantly Refreshed (read and rewritten) every few milliseconds.

Advantage of DRAM: It is extremely dense and cheap. Your PC's main 8GB/16GB memory is DRAM. Your CPU's small, ultra-fast Cache is SRAM.

2. Address Multiplexing in DRAM

DRAM chips have millions of locations. A 1 Megabyte chip requires 20 address lines (220). To save physical pins on the IC package, DRAM uses Address Multiplexing.

Instead of 20 address pins, the chip only has 10 address pins. The 20-bit address is split in half and sent in two steps:

1. Row Address: The first 10 bits are sent. The CPU activates the RAS' (Row Address Strobe) pin to tell the DRAM to latch this half of the address.
2. Column Address: The second 10 bits are sent on the EXACT SAME pins. The CPU activates the CAS' (Column Address Strobe) pin to latch the second half.
Roman Urdu: DRAM mein address ek Matrix (Grid) ki tarah hota hai. Jaise MS-Excel mein rows aur columns hote hain. Kyunke pins kam hoti hain, toh CPU pehle Row ka number bhejta hai aur "RAS" ka signal deta hai taake DRAM samajh jaye ke ye Row hai. Phir usi taar (wire) par Column ka number bhejta hai aur "CAS" ka signal deta hai. Phir un dono ko mila kar DRAM ko exact location mil jati hai.

3. DRAM Refresh Cycles

Because the capacitors leak, every single row in the DRAM must be refreshed (read and written back) periodically (e.g., every 64 milliseconds). During a refresh cycle, the DRAM cannot be accessed by the CPU for normal read/write operations.

Burst Refresh vs. Distributed Refresh:

  • Burst: The CPU stops all work and refreshes every row at once.
  • Distributed: The CPU refreshes one row, does some normal work, refreshes the next row, etc. (More commonly used).

Quick Revision: Lecture 42

  • DRAM: Uses capacitors to store data. Needs constant refreshing. Highly dense.
  • Address Multiplexing: Splitting the address into Row and Column halves to save pins on the IC.
  • RAS' / CAS': Row Address Strobe and Column Address Strobe. Used to latch the multiplexed addresses.
  • Refreshing: The mandatory process of recharging DRAM capacitors to prevent data loss.
