Lecture 43: Advanced DRAM Architectures

Standard DRAM (covered in Lecture 42) is slow because for every single byte of data, the CPU must send a Row Address (RAS), wait, then send a Column Address (CAS), and wait again. Engineers developed faster versions of DRAM to solve this bottleneck.

1. FPM (Fast Page Mode) DRAM

What is it? In FPM, once a Row Address is selected, the DRAM keeps that row (or "page") open. The CPU can then just send multiple different Column Addresses rapidly to read multiple bytes from the same row without re-sending the Row Address.

Roman Urdu: Farz karein aap ek kitaab (Memory) parh rahay hain. Normal DRAM mein CPU har lafz parhne ke baad kitaab band karta hai aur phir naya lafz parhne ke liye wahi page dobara kholta hai. FPM DRAM mein CPU ek dafa page (Row) khol leta hai, aur us page par mojood saaray lafz (Columns) jaldi jaldi parh leta hai bina kitaab band kiye.

2. EDO (Extended Data Out) DRAM

What is it? An improvement over FPM. In EDO DRAM, the output data remains valid on the data pins even while the CPU is sending the next column address. This overlapping of operations speeds up reading significantly.

3. SDRAM (Synchronous DRAM)

What is it? Older DRAMs were asynchronous (they didn't care about the CPU's main clock, they operated on their own internal delays). SDRAM is tied directly to the system clock. All read/write operations happen exactly on the rising edge of the clock pulse. This allows the memory to work in perfect harmony with the CPU, transferring data in high-speed "bursts".

4. DDR (Double Data Rate) SDRAM

What is it? Standard SDRAM transfers 1 word of data per clock cycle (on the rising edge). DDR SDRAM transfers data on BOTH the rising edge and the falling edge of the clock. This effectively doubles the speed without increasing the clock frequency.

Roman Urdu: Normal SDRAM clock ki 'tick' (upward edge) par data bhejta hai aur 'tock' (downward edge) par farigh rehta hai. DDR SDRAM 'tick' aur 'tock' dono par data bhejta hai, jiski wajah se speed double (2x) ho jati hai!

Quick Revision: Lecture 43

  • FPM DRAM: Holds the Row (Page) open to read multiple columns faster.
  • EDO DRAM: Overlaps data output with the next address setup.
  • SDRAM: Synchronized with the CPU clock for burst transfers.
  • DDR SDRAM: Transfers data on both the rising (↑) and falling (↓) edges of the clock.

Lecture 44: Flash Memory & Special Memories

1. Flash Memory Architecture

Flash Memory is a non-volatile storage technology (keeps data when power is off) that can be electrically erased and reprogrammed in large blocks. It is the technology behind USB drives and SSDs.

How it works: It uses a special MOS transistor with a Floating Gate. By applying a high voltage, electrons are forced through a thin oxide layer and trapped inside the floating gate. Because it is surrounded by insulation, the electrons stay trapped for years (representing a '0'). To erase it, a reverse voltage pulls the electrons back out (representing a '1').

NOR vs. NAND Flash

NOR Flash: Allows Random Access (you can read any specific byte instantly). Used for storing BIOS and firmware where the CPU needs to execute code directly from memory.
NAND Flash: Allows only Serial Access (read in blocks/pages). It is much denser, cheaper, and faster for bulk writing. Used in USB flash drives and SD cards.

2. Special Memories (FIFO & LIFO)

A. FIFO (First In, First Out)

Data written first is the first one to be read out. It acts like a pipeline or a queue.

Why is it used? Used as a Buffer between two devices running at different speeds. For example, a fast CPU sends a document to a slow Printer. The CPU dumps the data into a FIFO buffer and moves on, while the printer slowly reads from the FIFO.

B. LIFO (Last In, First Out)

Data written last is the first one to be read out. Also called a Stack.

Why is it used? Used heavily by Microprocessors. When a CPU jumps to run a sub-routine (a mini-program), it PUSHES its current return address onto the LIFO stack. When the sub-routine finishes, it POPs the address off the stack to know exactly where to return.

Roman Urdu:
FIFO: Yeh bank ki line ki tarah hai. Jo banda pehle line mein khara hoga, wo pehle farigh hoga.
LIFO: Yeh kitabon ke dher (stack) ki tarah hai. Jo kitaab aapne sab se aakhir mein dher ke upar rakhi thi, jab uthani paray gi toh sab se pehle wohi upar wali kitaab uthayenge.

Quick Revision: Lecture 44

  • Floating Gate: Traps electrons to store data permanently without power.
  • NOR Flash: Random access. Used for code execution (BIOS).
  • NAND Flash: Block access. High density. Used for USBs/SSDs.
  • FIFO: Queue system. Used for buffering between different-speed devices.
  • LIFO: Stack system. Used for holding return addresses in CPUs (PUSH/POP).

Lecture 45: Memory Expansion

Often, a single memory IC does not have the capacity (number of locations) or the word-size (data width) required by a computer system. Engineers combine multiple smaller memory chips to create a larger memory system. This is called Memory Expansion.

1. Word-Size Expansion (Increasing Data Width)

Scenario: The CPU has a 16-bit Data Bus, but you only have 8-bit RAM chips. (e.g., You want to build a 1K × 16 memory using two 1K × 8 chips).

How to Connect: You connect the chips in parallel.

  • Address Bus: Connected to BOTH chips simultaneously (A0 goes to A0 of Chip 1 AND Chip 2).
  • Control Pins (CS, WE, OE): Connected to BOTH chips simultaneously so they turn on and off together.
  • Data Bus: Kept SEPARATE. Chip 1 handles bits D0-D7. Chip 2 handles bits D8-D15. Together, they form a 16-bit word.
Roman Urdu: Word-Size barhane ka matlab hai ke memory ki chaurai (width) barhani hai. Hum 2 chips ko bilkul ek sath on karte hain. Aadha data pehli chip mein jata hai aur baqi ka aadha dusri chip mein. Address dono ko same diya jata hai taake dono ek hi location par apna apna hissa save karein.

2. Capacity Expansion (Increasing Locations)

Scenario: The CPU wants 2048 locations (2K), but your chips only hold 1024 locations (1K). The data width is fine (8-bits). (e.g., Expanding two 1K × 8 chips into one 2K × 8 memory).

How to Connect: You connect the chips sequentially using a Decoder.

  • Data Bus: Connected together. (D0-D7 of CPU goes to D0-D7 of BOTH chips).
  • Address Bus (Lower bits): The first 10 bits (A0 to A9) are shared between both chips to access the 1024 locations inside them.
  • Address Bus (Highest bit): The 11th bit (A10) from the CPU is used as a Selector. It is connected to a NOT gate or Decoder.
    → If A10 = 0, Chip 1 is enabled (Chip Select = 0), and Chip 2 is disabled.
    → If A10 = 1, Chip 1 is disabled, and Chip 2 is enabled.
Mathematical Rule for Capacity Expansion:
Number of Chips Required = Total Desired Capacity ÷ Capacity of One Chip.
Example: Need 4K locations using 1K chips? You need 4 chips, and a 2-to-4 Decoder to control their CS' pins using the top 2 address bits.
Roman Urdu: Capacity barhane ka matlab hai lambaai (length) barhana. Isme ek waqt mein sirf EK chip on hoti hai. Data wire dono pe lagi hoti hai par kaam sirf us chip mein hota hai jo "On" (Select) hoti hai. Sab se highest address wire batati hai ke memory ka upar wala hissa (Chip 1) use karna hai ya neechay wala (Chip 2).

Quick Revision: Lecture 45

  • Word-Size Expansion: Data buses split. Address and Control (CS) are shared. Both chips active simultaneously.
  • Capacity Expansion: Data buses shared. Lower addresses shared. Highest address bit(s) used via a Decoder to select which chip turns on. Only one chip active at a time.
  • Decoder Role: In capacity expansion, Decoders map the CPU's memory address space to the correct physical chip.
