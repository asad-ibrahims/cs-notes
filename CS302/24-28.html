Lecture 19: Introduction to Sequential Logic & Latches

1. Combinational vs. Sequential Circuits

What is it? Up until Lecture 18, we studied Combinational Circuits (like Adders, Multiplexers, Decoders). Now we enter the world of Sequential Circuits.

Combinational Circuit: Output depends ONLY on the present inputs. No memory is involved.
Sequential Circuit: Output depends on the present inputs AND the past history (previous states). It contains Memory Elements.
Asaan Alfaz Mein (Roman Urdu):
Combinational circuit mein "Yaad-dasht" (memory) nahi hoti. Jaise calculator mein aap 2+2 likhte hain toh 4 aata hai. Usko nahi pata isse pehle kya hua tha.
Sequential circuit mein memory hoti hai. Iska output is baat par depend karta hai ke abhi kya input diya gaya hai, aur pehle system kis haalat (state) mein tha. Jaise ek counter jo 1 ke baad 2, aur 2 ke baad 3 dikhata hai; usko yaad rakhna parta hai ke pichla number kya tha.

2. The Basic Memory Element: The Latch

What is it? A latch is the simplest type of temporary storage device that has two stable states (0 and 1). It is called a bistable multivibrator.

Why is it used? To "remember" or "hold" a single bit of data (0 or 1) even after the input signal is removed.

The S-R (Set-Reset) Latch

An S-R Latch can be built using two cross-coupled NOR gates or two cross-coupled NAND gates. "Set" means making the output (Q) = 1. "Reset" means making the output (Q) = 0.

Concept: Jab aap "Set" (S) ka button dabate hain, toh memory mein 1 store ho jata hai. Jab aap "Reset" (R) dabate hain, toh memory clear ho jati hai (0 ban jati hai). Agar aap dono nahi dabate, toh purani value mehfooz (hold) rehti hai.

Truth Table of Active-High S-R Latch (NOR based)

S (Set) R (Reset) Qnext State / Action
0 0 Qprev Hold (Yaad rakho, No Change)
0 1 0 Reset (Clear kardo)
1 0 1 Set (1 Store kardo)
1 1 Invalid Invalid (Dono 1 ek sath nahi de sakte)

Truth Table of Active-Low S'-R' Latch (NAND based)

Unlike the NOR latch, a NAND latch uses active-low inputs (usually denoted as S' and R' or S-bar and R-bar). It behaves the opposite way: it holds its state when both inputs are HIGH (1).

S' R' Qnext State / Action
1 1 Qprev Hold (No Change)
1 0 0 Reset
0 1 1 Set
0 0 Invalid Invalid
The Invalid State: If S=1 and R=1 simultaneously in a NOR latch, both outputs (Q and Q') try to become 0. But by definition, Q and Q' must be opposites. This causes a logical contradiction and unpredictable behavior. We MUST avoid this condition.

3. The Gated S-R Latch

To have better control, we add an "Enable" (EN) or "Clock" input. The latch will only change its state if Enable = 1.

Roman Urdu: Gated latch mein ek chokidar (Enable) bitha diya gaya hai. Jab Enable = 1 hoga, tabhi S aur R ki baat suni jayegi. Agar Enable = 0 hai, toh bahar chahe jo marzi S aur R change hote rahein, andar memory hold hi rahegi.

4. The Gated D (Data) Latch

Why is it used? To solve the "Invalid State" problem of the S-R Latch. We ensure S and R are never the same by using a single input 'D' and passing it through a NOT gate to generate the opposite signal for the other terminal.

Technical Definition: A D Latch has only one data input (D) and an Enable (EN) input. Whenever EN=1, the output Q simply follows the input D. When EN=0, Q holds its previous value.

Truth Table of D Latch

EN D Qnext State
0 X (Don't care) Qprev Hold
1 0 0 Reset
1 1 1 Set

Quick Revision: Lecture 19

  • Combinational: No memory. Sequential: Has memory.
  • Latch: Basic memory element storing 1 bit.
  • SR Latch: S=1 sets it to 1. R=1 resets it to 0. S=1, R=1 is INVALID.
  • Gated Latch: Only works when Enable/Clock is HIGH (1).
  • D Latch: Solves SR invalid problem. Output simply copies 'D' input when Enabled.
Common Confusion: What does Q and Q' mean?
Q is the normal output. Q' (Q-bar or Q-not) is the inverted output. If a circuit stores '1', it means Q=1 and Q'=0. They must always be opposite.

Lecture 20: Edge-Triggered Flip-Flops & Characteristics

1. Latches vs. Flip-Flops

Latches are level-triggered (they accept input as long as the Enable is HIGH). Flip-Flops are edge-triggered (they accept input ONLY at the exact moment the clock changes from 0 to 1, or 1 to 0).

Level vs Edge Triggering (Samajhne ki baat):
Farz karein Latch ek darwaza hai aur Flip-Flop ek camera hai.
Latch (Level): Jab tak Enable = 1 hai, darwaza khula hai. Koi bhi andar bahar aa ja sakta hai (input continously output ko change kar sakta hai).
Flip-Flop (Edge): Jaise camera click karta hai. Sirf us ek millisecond (clock ki edge) par jo data input pe mojood hota hai, wo usko "capture" (store) kar leta hai. Baqi time data change hota rahe, memory change nahi hogi.

2. Types of Edge-Triggered Flip-Flops

A. Edge-Triggered S-R Flip-Flop

Works exactly like an SR Latch, but only responds at the active clock edge (Positive Edge = transition from 0 to 1, Negative Edge = transition from 1 to 0).

B. Edge-Triggered D Flip-Flop

Copies the D input to the output Q only at the clock edge. Widely used for building registers.

C. J-K Flip-Flop (The Universal Flip-Flop)

Why is it used? The SR flip-flop has an invalid state (1, 1). The J-K flip-flop solves this by using internal feedback. J is like Set, K is like Reset. When both J=1 and K=1, instead of going invalid, it Toggles.

Toggle: To switch to the opposite state. If Q was 0, it becomes 1. If Q was 1, it becomes 0.

Truth Table of J-K Flip-Flop

Clock Edge J K Qnext Action
↑ (Rising) 0 0 Qprev Hold (No Change)
↑ (Rising) 0 1 0 Reset
↑ (Rising) 1 0 1 Set
↑ (Rising) 1 1 Q'prev Toggle (Flip state)

D. T (Toggle) Flip-Flop

Created by tying J and K together (J=K=T). When T=0, it holds. When T=1, it toggles on every clock edge.

Characteristic Equations (Important for Design & Exams!):
S-R Flip-Flop: Qnext = S + R'Qprev
D Flip-Flop: Qnext = D
J-K Flip-Flop: Qnext = JQ'prev + K'Qprev
T Flip-Flop: Qnext = T ⊕ Qprev

3. Asynchronous Inputs (PRESET and CLEAR)

Usually, a Flip-Flop waits for the clock edge to change state (Synchronous operation). But sometimes, we need to immediately set or clear the flip-flop regardless of the clock. We use special override pins called PRESET (sets Q to 1) and CLEAR (resets Q to 0).

Asynchronous Inputs: Yeh emergency override buttons hain. Inhe Clock ki zaroorat nahi hoti. Agar aap CLEAR daba dein, toh output fauran 0 ho jayega chahe clock aa rahi ho ya nahi.

4. Operating Characteristics

  • Setup Time (ts): The minimum time the input data must be stable before the clock edge arrives.
  • Hold Time (th): The minimum time the input data must remain stable after the clock edge has passed.
  • Propagation Delay (tp): The time it takes for the output to change after the clock edge triggers.

Quick Revision: Lecture 20

  • Flip-Flops are edge-triggered (react to 0->1 or 1->0 transition).
  • J-K Flip-Flop solves the SR invalid state problem. J=1,K=1 causes a TOGGLE.
  • T Flip-Flop toggles when input is 1, holds when 0.
  • PRESET/CLEAR are asynchronous; they don't wait for the clock.
  • Setup Time: Stable time required before clock. Hold Time: Stable time required after clock.
Common Confusion: What is a Clock Edge?
A digital clock signal alternates between 0 and 1 continuously (0-1-0-1...). The exact moment it goes from 0 up to 1 is the "Positive Edge" (or Rising Edge). Flip-Flops only "look" at inputs at this split second.

Lecture 21: Flip-Flop Applications & Intro to Counters

1. Parallel Data Storage (Registers)

A single flip-flop stores 1 bit. If we want to store 4 bits, 8 bits, or 32 bits, we group flip-flops together. This group is called a Register.

Registers: Jaise hamare computer mein 32-bit ya 64-bit memory registers hotay hain, woh asal mein 32 ya 64 D-Flip-Flops hote hain jo ek sath aik hi clock par kaam karte hain. Sab ek sath apna apna bit store kar lete hain.

2. Frequency Division

If we configure a J-K flip-flop to Toggle mode (J=1, K=1) and feed a clock signal into it, the output Q will change state every clock cycle. It takes two clock cycles for Q to complete one full cycle (0->1->0).

Formula: Output Frequency = Input Frequency / 2
fout = fin / 2

If we cascade (connect) another flip-flop, it divides by 2 again, making the total division by 4. This is highly used in digital clocks to reduce a high-speed crystal oscillator frequency down to 1 Hz (1 second).

3. Introduction to Counters

A counter is a specialized register that goes through a predetermined sequence of states (like 0, 1, 2, 3...) upon the application of clock pulses.

Types of Counters

  1. Asynchronous (Ripple) Counters: The clock is connected only to the first flip-flop. The output of the first flip-flop acts as the clock for the second, and so on.
  2. Synchronous Counters: The same master clock is connected to ALL flip-flops simultaneously.
Asynchronous vs Synchronous (Example):
Asynchronous: Aik line mein 4 log kharay hain. Pehla doosre ko awaz lagata hai, doosra teesre ko, teesra chothe ko. Message pohnchne mein delay (time) lagta hai. Isay "Ripple" delay kehte hain.
Synchronous: Aik speaker laga hai, chaaron log ek hi waqt (simultaneously) awaz sunte hain aur ek sath action lete hain. Isme delay nahi hota.

Quick Revision: Lecture 21

  • Register: A group of Flip-Flops used to store multiple bits of data.
  • Frequency Division: A toggling FF divides the clock frequency by 2.
  • Counters: Circuits that count clock pulses.
  • Asynchronous Counters: FF1 clocks FF2, FF2 clocks FF3 (Ripple effect). Slower.
  • Synchronous Counters: Master clock connected to all FFs. Faster.

Lecture 22: Asynchronous (Ripple) Counters

1. 2-Bit Asynchronous Binary Counter

We use two J-K flip-flops. Both are set in Toggle mode (J=1, K=1).
- The main Clock is connected to FF0 (the Least Significant Bit, LSB).
- The Output Q0 of FF0 is connected to the Clock input of FF1.

Note: Usually, Negative-Edge Triggered flip-flops are used so that the next FF toggles when the previous Q goes from 1 to 0.

Counting Sequence (2-Bit):

Clock Pulse Q1 (MSB) Q0 (LSB) Decimal Value
Initial 0 0 0
1 0 1 1
2 1 0 2
3 1 1 3
4 0 0 0 (Recycles)

2. Modulus of a Counter (MOD Number)

MOD Number: The total number of unique states a counter goes through before recycling. A counter with 'n' flip-flops has a maximum MOD of 2n.

A 2-bit counter is a MOD-4 counter (counts 0, 1, 2, 3). A 3-bit counter is a MOD-8 counter. A 4-bit counter is a MOD-16 counter.

3. Asynchronous Decade Counter (MOD-10)

What if we want to count from 0 to 9, and then reset to 0? (Like a normal digital clock digit).
A 4-bit counter naturally counts up to 15 (1111). To make it a MOD-10 counter, we must forcefully reset all flip-flops to 0 when it tries to reach 10 (Binary 1010).

MOD-10 Kaise Banta Hai?
4-bit counter 0 se 9 (1001) tak normal count karega. Jab agla clock ayega, to output 10 (1010) banne ki koshish karega. 1010 mein Q3=1 aur Q1=1 hai. Hum Q3 aur Q1 ko ek NAND gate mein daal kar uska output Flip-Flops ke "CLEAR" pin par laga dete hain. Jaise hi 1010 banta hai, NAND gate zero bhejta hai aur foran saare FFs reset hokar 0000 ban jate hain.

4. Asynchronous Down Counter

To count downwards (3, 2, 1, 0...), instead of connecting the true output Q to the next clock, we connect the inverted output Q' to the clock of the next flip-flop.

Maximum Frequency Formula (Ripple Counters):
Because propagation delays accumulate through each flip-flop, the maximum clock frequency is limited.
fmax = 1 / (N × tpd)
Where 'N' is the number of flip-flops and 'tpd' is the propagation delay of one flip-flop.

Quick Revision: Lecture 22

  • Ripple Counter: Because the clock signal ripples through the FFs one by one.
  • MOD Number: Maximum states = 2n. E.g., 3 FFs = MOD-8.
  • Decade Counter (MOD-10): Uses a NAND gate to detect 1010 and clears the FFs to 0000.
  • Down Counter: Connect Q' to the next clock instead of Q.
Propagation Delay Issue: Because each FF waits for the previous one to trigger it, the delays add up. In a large asynchronous counter, the last FF might change so late that the output briefly shows a wrong number (Glitch). This is why Synchronous counters are preferred.

Lecture 23: Synchronous Counters

1. Why Synchronous Counters?

To solve the propagation delay problem of asynchronous counters. In synchronous counters, the master clock is connected directly to the clock pins of ALL flip-flops. They all trigger at the exact same time.

Roman Urdu: Asynchronous mein ek FF doosre ka wait karta tha jisse delay (glitches) aate the. Synchronous mein sabko ek hi clock milti hai, toh sab ek sath decide karte hain ke unhe change hona hai ya nahi. Par ab sawal yeh hai: Agar clock sabko ek sath mil rahi hai, toh FF ko kaise pata chalega ke use toggle karna hai ya nahi? Iske liye hum J aur K inputs par logic gates (AND gates) lagate hain!

2. 2-Bit Synchronous Binary Counter

Using two J-K flip-flops (FF0 and FF1):

  • Clock: Connected to both FF0 and FF1.
  • FF0 (LSB): Must toggle on every clock. So, J0 = 1, K0 = 1.
  • FF1 (MSB): Should only toggle when FF0 is 1. So, J1 = Q0, K1 = Q0.

3. 3-Bit Synchronous Binary Counter

Adding a third flip-flop (FF2):

  • FF2: Should only toggle when BOTH FF0 and FF1 are 1 (Binary 011 -> next is 100).
  • Therefore, J2 = Q0 AND Q1. K2 = Q0 AND Q1.
  • We use an AND gate connected to Q0 and Q1, and feed its output into J2 and K2.

4. 4-Bit Synchronous Binary Counter

The logic continues:

  • FF0 toggles always: J0=1, K0=1
  • FF1 toggles if Q0=1: J1=Q0, K1=Q0
  • FF2 toggles if Q0=1 AND Q1=1: J2=Q0·Q1, K2=Q0·Q1
  • FF3 toggles if Q0=1 AND Q1=1 AND Q2=1: J3=Q0·Q1·Q2, K3=Q0·Q1·Q2
General Rule for Synchronous Counters: A flip-flop toggles only when all the preceding (lower order) flip-flops are in the HIGH (1) state. We achieve this using AND gates cascaded between stages.

5. Synchronous Decade Counter (BCD Counter)

Similar to the asynchronous decade counter, this counts from 0 to 9. However, the logic for J and K inputs is modified using Karnaugh Maps (K-Maps) during the design phase so that after state 9 (1001), the next clock pulse forces the state back to 0 (0000) simultaneously without any glitches.

Quick Revision: Lecture 23

  • Synchronous Counter: All Flip-Flops receive the same clock pulse at the same time.
  • No Propagation Delay Accumulation: Faster and more reliable than asynchronous ripple counters.
  • Logic Requirement: Requires extra logic gates (AND gates) to control the J and K inputs to tell each FF when to toggle.
  • J-K Logic Rule: Jn = Kn = Q0 · Q1 · ... · Qn-1

Lecture 24: Up/Down Counters & Counter Design

1. Synchronous Up/Down Counter

What is it? A single counter circuit that can count both upwards (0,1,2,3...) and downwards (3,2,1,0...) based on a control signal.

Why is it used? In real-world applications (like a digital parking lot counter), cars enter (count up) and leave (count down). We need a single circuit to handle both operations.

Mode Control Input (M): A special input pin used to decide the counting direction. Usually:
If M = 0, the counter counts UP.
If M = 1, the counter counts DOWN.
Roman Urdu: Up/Down counter mein ek "Direction Switch" (M) lagaya jata hai. Jab M=0 hota hai, toh next flip-flop purane flip-flop ke true output (Q) se signal leta hai aur up-counting hoti hai. Jab M=1 hota hai, toh woh inverted output (Q') se signal leta hai aur down-counting shuru ho jati hai. Yeh logic multiplexers (ya AND-OR gates) ke zariye implement hoti hai.

2. General Design Procedure for Sequential Circuits

How do engineers design custom counters (e.g., a counter that counts 0, 2, 5, 7 and repeats)? They follow a strict 5-step process:

  1. State Diagram: Draw a visual map showing circles for states (numbers) and arrows for transitions.
  2. Next-State Table: Make a table listing the Present State and the desired Next State.
  3. Flip-Flop Transition Table: Decide which Flip-Flop (e.g., J-K) to use. Use its "Excitation Table" to find out what inputs are needed to make the jump from Present to Next state.
  4. K-Maps: Create Karnaugh Maps for every J and K input to simplify the Boolean logic.
  5. Logic Circuit: Draw the final circuit using Flip-Flops and logic gates based on the K-Map equations.
J-K Excitation Table (Very Important for Design):
0 → 0 : J=0, K=X (Don't care)
0 → 1 : J=1, K=X
1 → 0 : J=X, K=1
1 → 1 : J=X, K=0

Quick Revision: Lecture 24

  • Up/Down Counter: Uses a Mode control line to switch between counting directions.
  • Design Step 1: State Diagram (Visual representation).
  • Design Step 2: Next-State table.
  • Design Step 3: Excitation Table (Tells you what input is needed for a desired output change).
  • Design Step 4 & 5: K-Maps for simplification and final circuit drawing.

Lecture 25: Introduction to Shift Registers (SISO & SIPO)

1. What is a Shift Register?

Definition: A shift register is a type of digital circuit made by cascading (connecting in series) multiple Flip-Flops. It is used to store data AND shift it either to the left or right upon every clock pulse.

They are primarily made using D Flip-Flops because whatever is at the 'D' input simply transfers to the 'Q' output at the clock edge.

Roman Urdu: Jaise ek paani ke pipe mein aap ek taraf se goliyaan daalte hain, aur pichli goli agli goli ko aage dhakka deti hai. Shift register mein bit (0 ya 1) andar jata hai, aur har clock ki tick par woh agle Flip-Flop mein "shift" (khisak) jata hai.

2. SISO (Serial-In, Serial-Out)

Data is entered one bit at a time (serially), and it comes out the other end one bit at a time.

Why is it used? Primarily used for introducing a time delay in digital signals. If you have a 4-bit SISO shift register, the data you put in will come out exactly 4 clock cycles later.

3. SIPO (Serial-In, Parallel-Out)

Data is entered one bit at a time (serially). However, the output is taken from the Q pins of ALL flip-flops simultaneously (in parallel).

Application: Serial-to-Parallel Conversion.
Imagine receiving data over a single wire (like a USB or network cable). Your computer's processor needs data in 8-bit or 16-bit parallel chunks. A SIPO register takes the single-file data, lines it up, and then hands it all at once to the processor.

Working Example (4-bit SIPO):

Let's shift in the binary number 1011 (entering right-most bit '1' first):

Clock Pulse Data In Q0 Q1 Q2 Q3
Initial-0000
111000
211100
300110
411011

After 4 clock pulses, the data 1011 is available in parallel across Q0-Q3.

Quick Revision: Lecture 25

  • Shift Register: Formed by D Flip-Flops. Stores and shifts data.
  • SISO: Serial-In Serial-Out. Used as a digital delay line.
  • SIPO: Serial-In Parallel-Out. Converts serial communication (1 wire) to parallel data (multiple wires).

Lecture 26: Shift Registers (PISO, PIPO & Bidirectional)

1. PISO (Parallel-In, Serial-Out)

What is it? Data is loaded into all flip-flops simultaneously (in parallel), but is shifted out one bit at a time (serially).

Why is it used? For Parallel-to-Serial Conversion. When a processor (which works in parallel) wants to send data over a single wire (like an internet cable), a PISO register takes the whole chunk of data and fires it out bit-by-bit.

Concept: Isme ek "Shift/Load" control pin hoti hai. Jab pin = 0 (Load), toh poora data ek jhatke mein saare FFs mein ghus jata hai. Phir jab pin = 1 (Shift) karte hain, toh data ek ek karke bahar nikalna shuru hota hai.

2. PIPO (Parallel-In, Parallel-Out)

Data goes in all at once, and comes out all at once.

Note: A PIPO register doesn't actually "shift" anything. It just acts as a standard temporary storage register (like the ones we studied in Lecture 21). It is extremely fast because loading and reading take only 1 clock cycle.

3. Bidirectional Shift Registers

Standard shift registers only shift right. A bidirectional shift register can shift data to the Right OR Left depending on a control signal (usually named RIGHT/LEFT').

How it works: Multiplexers (or logic gates) are placed in front of every D flip-flop.
- If moving RIGHT, the MUX connects Q0 to D1.
- If moving LEFT, the MUX connects Q1 to D0.

Quick Revision: Lecture 26

  • PISO: Parallel to Serial converter. Used for transmission over single lines.
  • Shift/Load Control: Required in PISO to decide whether to load data in or shift it out.
  • PIPO: Basic storage register. No actual shifting happens. Fastest operation.
  • Bidirectional: Can shift left or right using logic gates to route the data accordingly.

Lecture 27: Shift Register Counters

Shift registers can be connected back onto themselves to create special types of counters. They don't count in binary (0, 1, 2, 3), but they create specific patterns useful in digital timing and control.

1. The Ring Counter

What is it? A shift register where the output of the LAST flip-flop is connected directly to the input of the FIRST flip-flop (Qlast to Dfirst).

Kese Kaam Karta Hai? Isme ek hi '1' hota hai jo gol gol ghoomta rehta hai. Jaise: 1000 → 0100 → 0010 → 0001 → 1000. Yeh bilkul "passing the parcel" game ki tarah hai.
MOD of Ring Counter: A Ring Counter with N flip-flops has N states (MOD-N). (A normal 4-bit counter has 16 states, but a 4-bit Ring counter has only 4 states).

2. The Johnson Counter (Twisted Ring Counter)

What is it? Similar to a Ring Counter, but the Inverted Output (Q') of the last flip-flop is fed back into the input of the first flip-flop.

Sequence (4-bit):
0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000 (repeats).

MOD of Johnson Counter: A Johnson Counter with N flip-flops has 2N states (MOD-2N). (A 4-bit Johnson counter has 8 states).

Why use it? It gives you more states than a Ring counter using the same number of flip-flops, and is often used to control stepping motors or generate complex waveforms.

Quick Revision: Lecture 27

  • Ring Counter: Last Q fed to first D. MOD = N. Only one '1' circulates.
  • Johnson Counter: Last Q' fed to first D. MOD = 2N. Fills with 1s, then empties with 0s.
  • Use Case: They are used as sequence generators, timing controllers, and in motor controls.
Glitch Avoidance: Shift register counters are heavily preferred for decoding because, unlike binary counters, only ONE flip-flop changes state at a time in a Johnson counter (like Gray code), so there are no decoding glitches!

Lecture 28: Introduction to Memory

1. Memory Basics

In digital systems, we need to store large amounts of data. Flip-flops and registers are too big and expensive for storing megabytes of data, so we use dedicated Memory Chips.

Important Memory Terms:

  • Bit: A single 0 or 1.
  • Byte: 8 bits.
  • Word: A complete unit of information processed by the computer (can be 16-bit, 32-bit, or 64-bit).
  • Address Bus: The wires that tell the memory WHERE to look. (Like a house address).
  • Data Bus: The wires that carry the actual data in or out. (Like the people moving in or out of the house).
Capacity Formula:
If a memory chip has N address lines and M data lines:
Number of locations = 2N
Total Capacity (in bits) = 2N × M
Roman Urdu: Agar memory chip ke paas 10 address wires hain, toh 210 = 1024 locations hongi. Har location pe kitna data hoga? Woh Data Bus (M) par depend karta hai. Agar data bus 8-bit ki hai, toh total capacity 1024 bytes ban jayegi.

2. ROM (Read-Only Memory)

What is it? Non-volatile memory. Data is permanently written into it. If the power turns off, the data is NOT lost.

Uses: Storing the BIOS of a computer, firmware for microwaves and washing machines.

  • PROM: Programmable ROM (Can be written to exactly once by the user).
  • EPROM: Erasable PROM (Erased using UV light).
  • EEPROM: Electrically Erasable PROM (Erased using electrical signals; modern Flash memory like USB drives are based on this).

3. RAM (Random Access Memory)

What is it? Volatile memory. You can Read and Write to it incredibly fast, but if the power is cut, all data is instantly lost.

  • SRAM (Static RAM): Made using Flip-Flops. Very fast, but takes up a lot of physical space. Used for CPU Cache.
  • DRAM (Dynamic RAM): Made using tiny Capacitors. It is slower because capacitors leak charge and must be constantly "refreshed", but it holds way more data in less space. Used for Main System Memory (e.g., your 8GB or 16GB PC RAM).

Quick Revision: Lecture 28

  • Memory Capacity: Calculated as 2(Address lines) × Data bits.
  • ROM: Non-volatile, permanent storage. (PROM, EPROM, EEPROM).
  • RAM: Volatile, temporary working memory.
  • SRAM vs DRAM: SRAM uses flip-flops (fast, large, no refresh). DRAM uses capacitors (slower, dense, requires constant refreshing).
