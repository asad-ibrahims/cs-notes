Lecture 29: Flash Memory & Memory Expansion

1. Flash Memory Operations

Flash Memory is an advanced form of EEPROM (Electrically Erasable Programmable Read-Only Memory). It is high-density, non-volatile, and can be read/written electrically. It uses special MOS transistors with a "floating gate" to trap electrons (storing data).

2. Memory Expansion

What is it? Often, a single memory chip doesn't have enough capacity (locations) or word size (data bits) for a CPU. We connect multiple identical memory chips to "expand" the memory system.

Why is it used? To meet the data-width (e.g., 8-bit to 16-bit) and address-space requirements of a computer without needing to invent a custom chip.

A. Word-Size Expansion (Increasing Data Bus Width)

If you have a CPU that processes 16-bit words, but your memory chips are only 8-bits wide, you use TWO 8-bit chips in parallel.

How to wire it:
- Address Lines: Connected together (CPU Address 0 goes to A0 of both chips).
- Chip Select (CS): Connected together (Both turn on at the same time).
- Data Lines: Kept separate! Chip 1 provides bits D0-D7. Chip 2 provides bits D8-D15.

B. Capacity Expansion (Increasing Number of Locations)

If you have two 1K (1024 locations) memory chips and you want a 2K (2048 locations) memory.

How to wire it:
- Data Lines: Connected together (Both share D0-D7).
- Address Lines: Lower address lines are shared. The Most Significant Bit (MSB) of the CPU's address bus is used to select WHICH chip turns on (using a Decoder or directly to CS).
Roman Urdu: Asaan alfaz mein, agar data ki "chaudai" (width) barhani hai (jaise 8-bit se 16-bit), toh dono chips ko ek sath on karte hain. Agar memory ki "lambaai" (capacity) barhani hai, toh ek waqt mein sirf ek chip on hoti hai; jab pehli chip full ho jati hai toh address ka MSB (sabse bada bit) dusri chip ko on kar deta hai.

Quick Revision: Lecture 29

  • Flash Memory: High density, non-volatile, block-erasable using floating gate tech.
  • Word-Size Expansion: Connect Data buses separately, share Address and CS lines.
  • Capacity Expansion: Connect Data buses together, use highest Address bit to control Chip Select (CS).

Lecture 30: Special Memories & Programmable Logic Devices (PLDs)

1. Special Types of Memory

  • FIFO (First In First Out): Used as buffers between two devices operating at different speeds (e.g., CPU and Keyboard). The first bit written is the first one read.
  • LIFO (Last In First Out): Known as a "Stack". Used heavily in microprocessors for storing return addresses during subroutines. The last item pushed in is the first one popped out.

2. Introduction to PLDs (Programmable Logic Devices)

What is it? Instead of using fixed logic gates (like 7400 series AND/OR ICs), a PLD is a blank chip containing a massive array of gates. The user "programs" the connections between these gates to create custom digital circuits.

Roman Urdu: Pehle har logic circuit banane ke liye alag alag ICs (AND, OR, NOT) khareed kar unhe wires se jodna parta tha (Hardware implementation). PLD ek "kora kaghaz" (blank slate) hai. Aap software mein Boolean equation likhte hain, aur woh PLD ke andar ke connections ko fuse/anti-fuse ke zariye set kar deta hai. Is se jagah aur time dono bachte hain.

3. Architecture of PLDs (AND-OR Arrays)

Most PLDs are based on the standard Sum-Of-Products (SOP) Boolean form. They have a massive array of AND gates followed by an array of OR gates.

A. PROM (Programmable ROM) as a PLD

A PROM has a Fixed AND array (Decoder) and a Programmable OR array. Since the AND array is fully decoded, it generates every possible minterm. It is good for table lookups but inefficient for simple logic equations.

B. PAL (Programmable Array Logic)

PAL Architecture: Has a Programmable AND array and a Fixed OR array.

This is the most popular basic PLD. You can program exactly which inputs go into the AND gates (making product terms), but those AND gates are permanently wired to specific OR gates. It is faster and cheaper than PROM.

Quick Revision: Lecture 30

  • FIFO: First In First Out (Data Buffers).
  • LIFO: Last In First Out (CPU Stacks).
  • PROM: Fixed AND, Programmable OR. (Generates all minterms).
  • PAL: Programmable AND, Fixed OR. (Faster, cheaper, very common).

Lecture 31: PLA, GAL, CPLD & FPGA

1. PLA (Programmable Logic Array)

PLA Architecture: Has both a Programmable AND array AND a Programmable OR array.

It provides the maximum flexibility. You can create any product term and connect it to any OR gate. However, because both arrays are programmable, it has higher propagation delay (it is slower) and is more complex to manufacture than a PAL.

Roman Urdu Yaad Rakhne Ka Tarika:
- PROM: AND fix, OR set karo.
- PAL: AND set karo, OR fix hai.
- PLA: Dono apni marzi se set karo (Full control, but slow).

2. GAL (Generic Array Logic)

A GAL is essentially a PAL that is reprogrammable. It uses EEPROM technology instead of permanent fuses. It also includes an OLMC (Output Logic Macrocell) which allows the user to program the output pins to be active-high, active-low, or connected to flip-flops for sequential logic.

3. Complex PLDs (CPLD)

What is it? When a single PAL/GAL isn't enough, we use a CPLD. A CPLD contains multiple SPLDs (Simple PLDs like PAL blocks) on a single chip, all connected together by a Global Programmable Interconnect matrix.

4. FPGA (Field Programmable Gate Array)

What is it? The most advanced programmable logic. Unlike PLDs that use AND-OR arrays, FPGAs use Logic Blocks (usually based on Look-Up Tables or LUTs), highly flexible programmable interconnects, and I/O blocks. They are used to implement entire computer processors on a single chip.

Quick Revision: Lecture 31

  • PLA: Programmable AND, Programmable OR. (Most flexible, but slower).
  • GAL: Reprogrammable PAL with OLMCs.
  • CPLD: Multiple PAL-like blocks combined on one chip.
  • FPGA: Very high density, based on Logic Blocks/LUTs instead of AND-OR arrays.

Lecture 32: Interfacing - Introduction to DACs

1. Digital to Analog Conversion (DAC)

Why is it used? The real world is Analog (temperature, voice, speed). Computers are Digital (0s and 1s). To control a real-world device (like driving a speaker or a motor), the computer's digital binary output must be converted into a continuous analog voltage or current. This is done by a DAC.

2. The Binary-Weighted Input DAC

This circuit uses a resistor network and an Operational Amplifier (Op-Amp) acting as a summing amplifier.

  • The Most Significant Bit (MSB) is connected to a resistor of value R.
  • The next bit is connected to 2R.
  • The next to 4R, then 8R, and so on.

When a bit is '1', current flows through its resistor. The Op-Amp sums these currents to produce an analog output voltage.

Disadvantage of Binary-Weighted DAC: For a high-resolution DAC (like 12-bit), the resistor for the LSB (Least Significant Bit) would need to be 211 = 2048 times larger than the MSB resistor. Manufacturing such a wide range of highly precise resistors on a single chip is practically impossible.

3. The R-2R Ladder DAC

What is it? To solve the resistor problem, the R-2R ladder uses only two values of resistors: R and 2R, arranged in a ladder network.

By using network theorems (like Thevenin's theorem), the circuit inherently halves the current at each node down the ladder, perfectly creating binary weighting without needing extreme resistor values.

Roman Urdu: Binary Weighted DAC ka masla yeh tha ke agar bits barhte the, toh resistors ki value aasmaan pe chali jati thi (bohot baday aur precise resistors chahiye thay). R-2R Ladder ne yeh masla hal kar diya kyunke usme chahe 4-bit ho ya 16-bit, sirf 2 hi qisam ke resistors use hote hain (Maslan 10k aur 20k ohm). Yeh banana sasta aur highly accurate hota hai.

Quick Revision: Lecture 32

  • DAC: Converts binary 0s and 1s into continuous analog voltages.
  • Binary-Weighted DAC: Uses scaling resistors (R, 2R, 4R, 8R). Hard to manufacture for many bits.
  • R-2R Ladder DAC: Uses only two resistor values (R and 2R). Standard and highly accurate.

Lecture 33: DAC Specifications & ADC Intro

1. Operational Characteristics of DACs

Based on the official handout specifications, these are the key parameters used to evaluate a DAC:

1. Resolution: The smallest change in analog output voltage that can occur due to a change in the digital input (step size).
Formula: Step Size = Vref / (2n - 1)
2. Accuracy: A comparison of the actual output of a D/A converter with the expected/ideal theoretical output. It is usually expressed as a percentage of the full-scale output.

3. Linearity: The output of the D/A converter should be a straight line when the binary input is varied between its min and max values.

4. Monotonicity: The output voltage must always increase (or stay same) as the binary input increases. If an increase in binary input causes a drop in voltage, it exhibits non-monotonic behavior (which is bad).

5. Settling Time: Ideally, the analogue output should appear instantly. Practically, it takes time. Settling time is defined as the time the DAC takes to settle within ±1/2 Least Significant Bit (LSB) of its final value when a change occurs in the input.

2. Analog to Digital Conversion (ADC)

What is it? Converts real-world analog signals (like a microphone signal) into digital binary data (0s and 1s) so a computer can process it. It requires two main steps:

  1. Sampling: Taking "snapshots" of the continuous analog wave at discrete time intervals.
  2. Quantization: Assigning a specific binary code to the voltage level captured in the snapshot.
Roman Urdu: Real duniya ka signal continuous hota hai. ADC pehle us signal ki choti choti pictures kheenchat hai (Sampling), aur phir har picture ki voltage height ke mutabiq ek binary number (0101) chipka deta hai (Quantization).

3. Types of ADCs

A. Flash ADC (Simultaneous ADC)

The fastest type of ADC. It uses multiple comparators connected in parallel. For an n-bit ADC, it requires 2n - 1 comparators. (E.g., an 8-bit flash ADC needs 255 comparators!). It is extremely fast but very complex and expensive.

B. Successive Approximation ADC

The most widely used ADC. It uses a single Comparator, a DAC, and a Successive Approximation Register (SAR). It essentially "guesses" the digital value bit-by-bit from MSB to LSB. If it's an 8-bit ADC, it takes exactly 8 clock cycles to find the correct binary value.

Quick Revision: Lecture 33

  • Resolution: The smallest voltage change (Step Size).
  • Settling Time: Time taken to stabilize within ±1/2 LSB of final value.
  • Monotonicity: Output voltage must strictly increase with increasing binary input.
  • Flash ADC: Extremely fast, uses 2n - 1 comparators.
  • Successive Approximation ADC: Uses SAR logic, takes 'n' clock cycles for 'n' bits. Excellent balance of speed and complexity.
Common Confusion: DAC vs ADC
- Computer outputting sound to speakers = DAC (Digital to Analog).
- Microphone recording sound into computer = ADC (Analog to Digital).
