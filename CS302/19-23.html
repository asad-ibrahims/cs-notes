Lecture 19: Combinational vs Sequential Logic & Latches

1. Combinational vs. Sequential Circuits

Combinational Circuit: Output depends ONLY on the current inputs. (e.g., Adders, MUX). No memory.
Sequential Circuit: Output depends on current inputs AND the past history (previous state). It contains Memory Elements.
Roman Urdu: Combinational circuits mein "yaad dasht" (memory) nahi hoti. Jo input dogay, usi waqt output milega. Sequential circuits ko apna purana state yaad rehta hai. Jaise ek counter, jise yaad rakhna parta hai ke pichla number kya tha taa ke wo agla number bata sake.

2. The Latch (Basic Memory Element)

A latch is a temporary storage device that has two stable states (Bistable). It is used to store exactly 1 bit of information (0 or 1).

A. Active-High S-R (Set-Reset) Latch (NOR Based)

Made by cross-coupling two NOR gates. "Active-High" means the inputs activate when they are 1.

Roman Urdu: NAND aur NOR latch bilkul opposite kaam karte hain. NOR wale mein 1 dene se kaam hota hai, aur NAND wale mein 0 dene se. Dono mein S aur R dono ko ek sath active karna "Invalid" hai kyunki is se Q aur Q' dono same ho jate hain, jo logic rules ke khilaf hai (Q aur Q' hamesha opposite hone chahiye).

3. Gated S-R Latch & Gated D Latch

Gated S-R Latch: Adds an Enable (EN) input. If EN=0, the latch holds its state regardless of S and R. If EN=1, it works like a normal latch.

Gated D (Data) Latch: Solves the invalid state problem of the S-R latch. It uses an inverter so that S and R are never the same. It only has one input 'D'. If EN=1, Q simply copies D. If EN=0, it holds.

Quick Revision: Lecture 19

  • Sequential Logic = Combinational Logic + Memory.
  • NOR S-R Latch: S=1 sets to 1, R=1 resets to 0. S=1,R=1 is Invalid.
  • NAND S'-R' Latch: S'=0 sets to 1, R'=0 resets to 0. S'=0,R'=0 is Invalid.
  • D-Latch: Eliminates the invalid state. Copies Data (D) when Enabled.

Lecture 20: Edge-Triggered Flip-Flops

1. Latches vs. Flip-Flops

Latches are Level-Triggered: They respond to changes as long as the Enable signal is HIGH (or LOW).
Flip-Flops are Edge-Triggered: They only respond to changes during the exact instant the clock signal changes from 0 to 1 (Positive Edge) or 1 to 0 (Negative Edge).
Roman Urdu: Latch ek khule darwaze ki tarah hai. Jab tak darwaza (Enable) khula hai, input continuously output ko change karta rahega. Flip-Flop ek camera shutter ki tarah hai, jo sirf us ek microsecond mein data ko capture (store) karta hai jab clock pulse ki edge aati hai.

2. Types of Edge-Triggered Flip-Flops

We use a Pulse Transition Detector circuit inside flip-flops to ensure they only trigger on the edges.

A. Edge-Triggered D Flip-Flop

Copies the D input to Q at the active clock edge. Very popular for registers.

B. Edge-Triggered J-K Flip-Flop

Solves the S-R flip-flop invalid state by using feedback from the outputs. When J=1 and K=1, it Toggles.

Clock EdgeJKQnextAction
↑00QprevHold
↑010Reset
↑101Set
↑11Q'prevToggle

3. Asynchronous Inputs (PRESET and CLEAR)

These are special pins on a flip-flop that override the clock completely.

  • PRE (Preset): Immediately sets Q to 1.
  • CLR (Clear): Immediately resets Q to 0.
Roman Urdu: Preset aur Clear ko "Asynchronous" isliye kehte hain kyunki inhein Clock ki zaroorat nahi hoti. Yeh direct override buttons hain. Jab circuit ko power milti hai, toh pehle system ko reset karne ke liye Clear button use hota hai.

4. Master-Slave J-K Flip-Flop

Before edge-triggered FFs, engineers used a Master-Slave configuration to prevent "Race Conditions" (where the output oscillates uncontrollably). It uses two latches: a Master (triggers on positive pulse) and a Slave (triggers on negative pulse). Information transfers in two steps.

Quick Revision: Lecture 20

  • Edge-Triggering: Reacting only at the 0→1 or 1→0 transition of the clock.
  • J-K Flip Flop: When J=1, K=1, the state flips (Toggles) on the clock edge.
  • Asynchronous Inputs: PRESET and CLEAR do not wait for the clock edge.
  • Master-Slave: An older design to prevent race conditions, using two stages of latches.

Lecture 21: Flip-Flop Characteristics & Applications

1. Flip-Flop Operating Characteristics

To design reliable circuits, we must respect the physical timing limits of real-world flip-flops.

  • Setup Time (ts): The minimum time the input data (e.g., D or J/K) must be held stable before the active clock edge arrives.
  • Hold Time (th): The minimum time the input data must remain stable after the clock edge has occurred.
  • Propagation Delay (tPLH / tPHL): The time it takes for the output to actually change after the clock edge triggers. (PLH = Low to High, PHL = High to Low).
  • Maximum Clock Frequency (fmax): The highest speed the clock can run before the flip-flop stops functioning reliably.
Roman Urdu: Setup time ka matlab hai ke clock aane se thora pehle input ready hona chahiye. Hold time ka matlab hai ke clock guzarne ke kuch dair baad tak input change na ho, warna flip-flop confuse ho jayega aur ghalat data store kar lega.

2. Applications of Flip-Flops

A. Parallel Data Storage (Registers)

A group of D Flip-Flops sharing a single clock can store multiple bits of data simultaneously. An 8-bit register uses 8 D-flip-flops.

B. Frequency Division

If you connect a J-K Flip-Flop in Toggle mode (J=1, K=1), its output Q will change state once for every full clock cycle. This cuts the output frequency exactly in half.

Formula: fout = fin / 2

If you cascade (chain) 3 flip-flops together, the final output frequency will be fin / 23 = fin / 8.

3. Introduction to Counters

Counters are specialized registers designed to count clock pulses. They count in binary (00, 01, 10, 11...).

  • Asynchronous (Ripple) Counters: Clock is only connected to the first FF. Each FF triggers the next one.
  • Synchronous Counters: Clock is connected to ALL FFs simultaneously.

Quick Revision: Lecture 21

  • ts (Setup Time): Stable time needed BEFORE clock.
  • th (Hold Time): Stable time needed AFTER clock.
  • Registers: Multiple FFs used to store a binary word.
  • Frequency Divider: Toggling FF divides clock speed by 2.

Lecture 22: Asynchronous (Ripple) Counters

1. The Ripple Effect

In an asynchronous counter, only the first flip-flop (LSB) receives the external clock. The output (Q) of the first FF acts as the clock for the second FF, and so on. We use Negative-Edge triggered J-K Flip-Flops set to Toggle mode (J=1, K=1).

Roman Urdu: Asynchronous counter ko "Ripple" isliye kehte hain kyunki clock ka asar paani ki lehar (ripple) ki tarah ek FF se dosre mein flow karta hai. Is wajah se isme "Propagation Delay" (deri) paida hoti hai, kyunki har FF apne pichle FF ke trigger hone ka wait karta hai.

2. The MOD Number

MOD (Modulus): The maximum number of distinct states a counter goes through before resetting.
Formula: MOD = 2n (where n is the number of Flip-Flops).
  • 2 Flip-Flops = 22 = MOD-4 (Counts 0, 1, 2, 3)
  • 3 Flip-Flops = 23 = MOD-8 (Counts 0 to 7)
  • 4 Flip-Flops = 24 = MOD-16 (Counts 0 to 15)

3. Asynchronous Decade Counter (MOD-10)

Goal: A digital clock digit only goes from 0 to 9. A 4-bit counter naturally goes to 15. We must force it to reset at 10.

How it works: The binary number for 10 is 1010 (Q3=1, Q2=0, Q1=1, Q0=0). We connect the outputs Q3 and Q1 to a NAND gate. The output of this NAND gate is connected to the CLEAR (CLR) pins of all flip-flops (which are active-low). As soon as count reaches 10, the NAND gate outputs 0, instantly resetting all FFs to 0000.

Glitches: Because of the propagation delay in ripple counters, you might see a brief, incorrect state (a glitch) for a fraction of a nanosecond before the NAND gate clears everything. This is a major disadvantage of Ripple Counters.

Quick Revision: Lecture 22

  • Asynchronous = Ripple: Only first FF gets the main clock.
  • MOD Number: Total number of states = 2n.
  • Decade Counter: Resets at count 10 (1010) using a NAND gate on Q3 and Q1 connected to CLR.

Lecture 23: Asynchronous Down Counters & Synchronous Counters

1. Asynchronous Down Counter

To make an asynchronous counter count downwards (e.g., 7, 6, 5...), instead of connecting the normal output Q to the clock of the next flip-flop, we connect the inverted output Q' to the clock of the next flip-flop.

2. Cascading Asynchronous Counters

If we want to count higher than a single IC allows, we cascade them. For example, to make a MOD-60 counter (useful for seconds/minutes in a clock):

Cascade a MOD-10 (Decade) counter and a MOD-6 counter. Connect the MSB output of the MOD-10 to the clock input of the MOD-6.

3. Introduction to Synchronous Counters

Why use them? To eliminate the propagation delay glitches of Ripple Counters. In a synchronous counter, the Master Clock is connected directly to the clock pins of EVERY flip-flop simultaneously.

Roman Urdu: Synchronous counter mein saare Flip-Flops ko ek hi waqt mein Clock milti hai, isliye delay nahi hota. Lekin ab masla yeh hai ke sab ek sath toggle kar jayenge! Isko roknay ke liye hum AND gates lagate hain jo batate hain ke kis Flip-Flop ko kis waqt toggle (change) karna hai aur kisko hold rehna hai.

4. Synchronous Counter Design Logic

We use J-K Flip-Flops. The rule for binary counting is: A bit flips only when ALL previous lower-order bits are 1.

  • FF0 (LSB): Always toggles. J0 = 1, K0 = 1
  • FF1: Toggles only if Q0=1. J1 = Q0, K1 = Q0
  • FF2: Toggles only if Q0=1 AND Q1=1. J2 = Q0·Q1, K2 = Q0·Q1
  • FF3 (MSB): Toggles only if Q0=1 AND Q1=1 AND Q2=1. J3 = Q0·Q1·Q2, K3 = Q0·Q1·Q2

To achieve this, we place AND gates between the flip-flops to combine the Q outputs and feed them into the next J-K inputs.

Quick Revision: Lecture 23

  • Down Counter: Uses Q' for the clocking signal instead of Q.
  • Cascading: Connecting counters in series to multiply their MOD numbers (e.g. Mod 10 × Mod 6 = Mod 60).
  • Synchronous Counters: Clock shared across all FFs. No ripple delay. Faster and more reliable.
  • Sync Control: Uses AND logic (Jn = Kn = Q0·Q1...·Qn-1).
